## 🔄 Flow Matching 迭代过程详解

### 训练时：学习从噪声到真实动作的路径

```
时刻 t (0 到 1 之间的随机值)
│
├─ t=0.1 ────────────────────────────────────────────────────┐
│   混合: 0.9×噪声 + 0.1×真实动作                             │
│   Result: [0.7, -0.8, 0.3, ...]  (很多噪声)                │
│   Target: 学习速度方向指向真实动作                           │
│                                                             │
├─ t=0.5 ────────────────────────────────────────────────────┤
│   混合: 0.5×噪声 + 0.5×真实动作                             │
│   Result: [0.3, -0.2, 0.4, ...]  (一半一半)                │
│   Target: 继续优化速度方向                                  │
│                                                             │
├─ t=0.9 ────────────────────────────────────────────────────┤
│   混合: 0.1×噪声 + 0.9×真实动作                             │
│   Result: [0.05, 0.02, 0.18, ...] (接近真实)               │
│   Target: 微调最终动作                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘

损失函数: MSE(预测速度, 真实动作 - 噪声)
```

### 推理时：从噪声迭代到精确动作

```
初始化 (i=0)
┌──────────────────────────────────────┐
│ action = random(-1, 1) × action_mask │
│ [0.8, -0.6, 0.3, 0.9, ...]          │
└────────────┬─────────────────────────┘
             │
             ↓
    迭代 50 次 (i=1 to 50)
    ┌─────────────────────────────────────────┐
    │ t = i / 50                              │
    │ time_emb = SinusoidalEncoding(t)        │
    │                                         │
    │ ┌─────────────────────────────────┐    │
    │ │ 1. Encode current action        │    │
    │ │    action_tokens = encoder(     │    │
    │ │      action × action_mask       │    │
    │ │    )                            │    │
    │ └────────────┬────────────────────┘    │
    │              ↓                          │
    │ ┌─────────────────────────────────┐    │
    │ │ 2. Transformer processing       │    │
    │ │    x = transformer_layers(      │    │
    │ │      action_tokens,             │    │
    │ │      context_tokens,            │    │
    │ │      time_emb                   │    │
    │ │    )                            │    │
    │ └────────────┬────────────────────┘    │
    │              ↓                          │
    │ ┌─────────────────────────────────┐    │
    │ │ 3. Predict velocity             │    │
    │ │    velocity = mlp_head(         │    │
    │ │      pool(x)                    │    │
    │ │    )                            │    │
    │ └────────────┬────────────────────┘    │
    │              ↓                          │
    │ ┌─────────────────────────────────┐    │
    │ │ 4. Update action                │    │
    │ │    action += dt × velocity      │    │
    │ │    dt = 1/50 = 0.02             │    │
    │ └─────────────────────────────────┘    │
    └─────────────────────────────────────────┘
             │
             ↓
最终动作 [B, 1200]
reshape → [B, 50, 24]

动作演化过程：
i=0:  [0.8, -0.6, 0.3, ...]  (随机)
i=10: [0.6, -0.4, 0.25, ...] (开始有形状)
i=25: [0.3, -0.1, 0.15, ...] (越来越准)
i=50: [0.02, 0.01, 0.03, ...] (最终动作)
```

## 📚 两阶段训练流程

### Stage 1: 冻结 VLM，训练动作专家

```
┌─────────────────────────────────────────────────────────────────┐
│                        Stage 1 (5000 steps)                     │
│                    学习率: 1e-5, Batch Size: 16                 │
└─────────────────────────────────────────────────────────────────┘

组件状态：
┌────────────────────────┐
│  InternVL3-1B          │  🔒 requires_grad = False
│  (Vision-Language)     │     (参数冻结，不更新)
└───────────┬────────────┘
            │ 输出固定的语义特征
            ↓
┌────────────────────────┐
│  State Encoder         │  ✅ requires_grad = True
│  (Integration)         │     (正在训练)
└───────────┬────────────┘
            │
            ↓
┌────────────────────────┐
│  Flow Matching Head    │  ✅ requires_grad = True
│  (Action Expert)       │     (正在训练)
└────────────────────────┘

训练过程：
for step in range(5000):
    1. 从数据集获取 (obs, action_gt)
    2. fused_tokens = embedder(obs.images, obs.prompt)  # 冻结
    3. pred_velocity, noise = action_head(
           fused_tokens, obs.state, action_gt
       )  # 训练
    4. loss = MSE(pred_velocity, action_gt - noise)
    5. 只更新 action_head 和 state_encoder 的参数

目标：
  ✅ 让动作头学会利用预训练的语义特征
  ✅ 保持 VLM 的语言理解能力不被破坏
  ✅ 建立初步的视觉-动作映射

保存检查点: checkpoints/stage1/step_5000/
```

### Stage 2: 全模型微调

```
┌─────────────────────────────────────────────────────────────────┐
│                       Stage 2 (80000 steps)                     │
│                    学习率: 1e-5, Batch Size: 16                 │
│                    从 Stage 1 检查点恢复                         │
└─────────────────────────────────────────────────────────────────┘

组件状态：
┌────────────────────────┐
│  InternVL3-1B          │  ✅ requires_grad = True
│  (Vision-Language)     │     (参与微调)
└───────────┬────────────┘
            │ 适应机器人任务的语义
            ↓
┌────────────────────────┐
│  State Encoder         │  ✅ requires_grad = True
│  (Integration)         │     (继续训练)
└───────────┬────────────┘
            │
            ↓
┌────────────────────────┐
│  Flow Matching Head    │  ✅ requires_grad = True
│  (Action Expert)       │     (继续训练)
└────────────────────────┘

训练过程：
# 加载 Stage 1 检查点
load_checkpoint("checkpoints/stage1/step_5000")

for step in range(80000):
    1. 从数据集获取 (obs, action_gt)
    2. fused_tokens = embedder(obs.images, obs.prompt)  # 微调
    3. pred_velocity, noise = action_head(
           fused_tokens, obs.state, action_gt
       )  # 训练
    4. loss = MSE(pred_velocity, action_gt - noise)
    5. 更新所有参数（使用梯度裁剪 norm=1.0）

    if step % 2500 == 0:
        save_checkpoint(f"step_{step}")

目标：
  ✅ 端到端优化整个模型
  ✅ VLM 学习机器人任务特定的视觉-语言表示
  ✅ 提升最终性能

关键技巧：
  - 学习率预热 (1000 steps)
  - 梯度裁剪 (防止微调过程中的梯度爆炸)
  - 定期保存检查点
```

### 为什么不直接端到端训练？

```
❌ 直接端到端训练的问题：

┌─────────────────────────────────────┐
│  开始：                             │
│  VLM 理解 "抓取" = grab/pick up     │  ✅ 语义正确
│  VLM 理解 "红色" = red color        │
└─────────────────────────────────────┘
           ↓ 训练 80000 步
┌─────────────────────────────────────┐
│  结束：                             │
│  VLM "理解" = [0.2, -0.3, 0.1...]  │  ❌ 退化为特征提取器
│  丧失了语言的真正语义理解            │     (过拟合到训练集)
└─────────────────────────────────────┘

✅ 两阶段训练的优势：

Stage 1: 动作头学会"阅读"语义
  → VLM 输出保持语义性
  → 动作头适应这种语义表示

Stage 2: 整体微调但有约束
  → VLM 的语义理解已经被动作头"依赖"
  → 不会完全退化，只是适应任务
  → 保持泛化能力
```

### 数据流：从收集到部署

```

┌─────────────────────────────────────────────────────────────┐
│  lerobot-record --robot.type=so100 --task="抓取红色方块"     │
└────────────┬────────────────────────────────────────────────┘

             ↓
    ┌──────────────────┐
    │  Teleoperation   │  人类演示 (通过 leader arm 或手柄)
    │  Loop            │
    │  ┌────────────┐  │
    │  │1. Get obs  │  │  获取观测
    │  │2. Get act  │  │  记录人类动作
    │  │3. Execute  │  │  在机器人上执行
    │  │4. Save     │  │  保存到数据集
    │  └────────────┘  │
    └────────┬─────────┘
             │ 保存 50 episodes
             ↓
┌──────────────────────────────────────────────────────────────┐
│  data/my_task/                                               │
│    ├── data/chunk-000.parquet  (50 episodes × 200 frames)   │
│    ├── videos/episode_*/                                    │
│    └── meta/metadata.json                                   │
└────────────┬─────────────────────────────────────────────────┘
             │
```

```
  ├─ 你有多少数据？
  │  ├─ 少量 (50-100 demos)
```
